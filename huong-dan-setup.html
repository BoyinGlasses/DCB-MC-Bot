🎮 Hướng Dẫn Setup Discord Bot

Minecraft Server Monitor - Thông báo khi server online/offline

1

Cài đặt Node.js

Bot cần Node.js để chạy. Tải và cài đặt Node.js từ trang chủ:

Tải Node.js
💡 Lưu ý: Chọn phiên bản LTS (Long Term Support). Bot yêu cầu Node.js 18 trở lên.
2

Tạo Discord Bot trên Developer Portal

Đầu tiên, bạn cần tạo một Discord Application và Bot:

2.1. Truy cập Discord Developer Portal và đăng nhập.

2.2. Click "New Application" và đặt tên cho bot (ví dụ: "Minecraft Server Monitor").

📱

Ảnh minh họa: Discord Developer Portal - New Application

2.3. Vào tab "Bot" ở menu bên trái.

2.4. Click "Reset Token" để lấy Bot Token.

⚠️ Quan trọng: Copy và lưu lại Bot Token ngay lập tức! Token chỉ hiện một lần. Nếu mất, phải Reset Token mới.
Your Bot Token sẽ có dạng: MTEwMTQxOTA2MzQ1Njc4OTYxNA.GxXxXx.xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
3

Bật Message Content Intent

Bot cần quyền đọc nội dung tin nhắn để hoạt động:

3.1. Trong tab "Bot", kéo xuống phần "Privileged Gateway Intents".

3.2. Bật Message Content Intent (nhấn toggle).

⚙️

Ảnh minh họa: Toggle Message Content Intent

4

Invite Bot vào Discord Server

Bây giờ cần thêm bot vào server Discord của bạn:

4.1. Vào tab "OAuth2" → "URL Generator".

4.2. Trong phần "Scopes", tick chọn bot.

4.3. Trong phần "Bot Permissions", chọn:

  • ☑ Send Messages
  • ☑ Embed Links

4.4. Copy URL được tạo và dán vào trình duyệt.

4.5. Chọn server của bạn và click "Authorize".

🔗

Ảnh minh họa: OAuth2 URL Generator

5

Lấy Channel ID

Bot cần Channel ID để gửi thông báo:

5.1. Trong Discord, vào Settings → Advanced → Bật Developer Mode.

5.2. Quay lại server, right-click (nhấn chuột phải) vào channel mà bạn muốn bot gửi thông báo.

5.3. Click "Copy Channel ID".

💡 Mẹo: Nên tạo một channel riêng cho thông báo bot (ví dụ: #server-status).
6

Cài đặt Project

Tải project về máy:

6.1. Mở Terminal/Command Prompt và điều hướng đến thư mục project:

cd D:\minecraftserverbot

6.2. Cài đặt dependencies:

npm install

Đợi cho đến khi cài đặt hoàn tất...

7

Tạo file .env

Tạo file cấu hình cho bot:

7.1. Trong thư mục project, tạo file tên .env (có dấu chấm đằng trước).

7.2. Copy nội dung sau vào file:

# Discord Bot Configuration DISCORD_BOT_TOKEN=PASTE_BOT_TOKEN_CUA_BAN_TAI_DAY # Channel ID cho thông báo DISCORD_CHANNEL_ID=PASTE_CHANNEL_ID_TAI_DAY # Minecraft Server Address MC_SERVER_HOST=127.0.0.1 MC_SERVER_PORT=25565 # Polling interval (ms) - 30000 = 30 giay POLLING_INTERVAL_MS=30000

7.3. Thay thế các giá trị:

  • PASTE_BOT_TOKEN_CUA_BAN_TAI_DAY → Bot Token đã copy ở Bước 2
  • PASTE_CHANNEL_ID_TAI_DAY → Channel ID đã copy ở Bước 5
⚠️ Lưu ý: File .env chứa token bảo mật. Không chia sẻ file này với ai!
8

Chạy Bot

Tất cả đã sẵn sàng! Chạy bot:

npm start

Nếu thành công, bạn sẽ thấy:

=== Minecraft Server Discord Bot === [Config] Configuration validated successfully [Config] Server: 127.0.0.1:25565 [Config] Polling interval: 30000ms [Bot] Logging in to Discord... [Discord] Bot logged in as Minecraft Server Monitor#1234 [Discord] Target channel: server-status [Discord] Embed sent successfully [Bot] Polling started - interval: 30000ms
✅ Hoàn tất! Bot đã chạy và sẽ thông báo khi Minecraft server online/offline.
9

Bật Minecraft Server

Khi bạn bật Fabric server lên:

  • Bot sẽ tự động phát hiện sau tối đa 30 giây
  • Thông báo "🟢 Server is ONLINE!" sẽ được gửi vào Discord
  • Kèm theo: Server name, version, players, ping...

Khi server tắt:

  • Bot phát hiện và gửi "🔴 Server is OFFLINE"
!

Xử lý lỗi thường gặp

Bot không kết nối được?
→ Kiểm tra Bot Token đúng chưa
→ Kiểm tra Bot đã được invite vào server chưa
→ Kiểm tra đã bật Message Content Intent chưa
Không lấy được thông tin server?
→ Kiểm tra Minecraft server đã bật chưa
→ Kiểm tra MC_SERVER_HOST và MC_SERVER_PORT đúng chưa
→ Đảm bảo server đang bind đúng port
Channel not found?
→ Kiểm tra DISCORD_CHANNEL_ID đúng chưa
→ Bot phải có quyền truy cập vào channel đó

📋 Checklist Trước Khi Chạy

  • Đã cài Node.js
  • Đã tạo Discord Application và Bot
  • Đã copy Bot Token
  • Đã bật Message Content Intent
  • Đã invite Bot vào server
  • Đã bật Developer Mode và copy Channel ID
  • Đã chạy npm install
  • Đã tạo file .env với đầy đủ thông tin
  • Đã chạy npm start
