🌐 Server yêu cầu ZeroTier

Server này ở sau NAT/firewall, không thể truy cập trực tiếp. Bạn cần cài ZeroTier để kết nối.

Quá trình mất khoảng 5-10 phút

1 Tải ZeroTier

Truy cập: https://www.zerotier.com/download/

Tải phiên bản phù hợp với hệ điều hành của bạn (Windows/Mac/Linux).

2 Tạo tài khoản (miễn phí)

Đăng ký tại: https://my.zerotierier.com/

Chỉ cần email, không cần thẻ tín dụng.

3 Join Network

Mở ZeroTier client → paste Network ID bên dưới → click Join Network:

Network ID:

{{ztNetworkId}}

4 Lấy ZeroTier ID của bạn

Mở ZeroTier client → copy Node ID (10 ký tự hex, vd: a1b2c3d4e5).

Trên Windows: click phải vào ZeroTier icon ở system tray → Show Details → copy Node ID.

5 Gửi yêu cầu cho bot

Mở Discord → tìm {{serverName}} Bot → nhắn:

/zt-request zt-id:<your-zt-id> mc-username:<your-mc-name>

VD: /zt-request zt-id:a1b2c3d4e5f6g7h8 mc-username:Steve

6 Đợi admin duyệt

Admin sẽ duyệt yêu cầu của bạn (thường trong vài phút đến vài giờ).

Bot sẽ tự động DM cho bạn địa chỉ IP để kết nối khi được duyệt.

7 Kết nối Minecraft

Sau khi nhận IP từ bot:

  1. Mở Minecraft Java Edition
  2. Multiplayer → Add Server
  3. Server Address: paste IP từ bot (vd: 10.x.x.x:25565)
  4. Click Join Server

🎉 Xong! Chúc bạn chơi vui vẻ!

🆘 Troubleshooting

ZeroTier không connect được?
  • Check firewall/antivirus có chặn ZeroTier không
  • Thử restart ZeroTier service
  • Đợi 1-2 phút để ZeroTier handshake
Bot không phản hồi /zt-request?
  • Check bot đang online (status xanh)
  • Bạn đã join ZeroTier network chưa?
  • ZeroTier ID phải đúng 16 ký tự hex
Đã được duyệt nhưng không connect được Minecraft?
  • Check ZeroTier vẫn online (icon xanh)
  • IP từ bot phải là IP trong ZeroTier network (10.x.x.x)
  • Restart Minecraft client
