2 Vào Multiplayer

Từ menu chính, click Multiplayer → Add Server.

3 Nhập địa chỉ server

4 Kết nối

🆘 Gặp vấn đề?

  • Connection timed out: Kiểm tra firewall, antivirus có chặn port {{serverPort}} không
  • Server outdated: Server dùng version khác, hỏi admin về version chính xác
  • Unknown host: Kiểm tra lại địa chỉ IP/hostname
  • Liên hệ admin qua Discord để được hỗ trợ
