📚 Hướng dẫn lấy thông tin

Discord Bot Token
  1. Vào Discord Developer Portal
  2. Tạo New Application → đặt tên
  3. Vào tab Bot → click Reset Token
  4. Copy token (chỉ hiện 1 lần!)
  5. Bật Message Content Intent ở phía dưới
Channel ID
  1. Mở Discord → Settings → Advanced → bật Developer Mode
  2. Right-click channel muốn bot gửi thông báo → Copy Channel ID
ZeroTier Network ID
  1. Tạo account tại my.zerotierier.com
  2. Tạo Network mới
  3. Copy Network ID (16 ký tự hex)
  4. Trong Settings → tạo API Token
